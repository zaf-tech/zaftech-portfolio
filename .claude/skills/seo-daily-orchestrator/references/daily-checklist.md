# Daily SEO checklist for Zaftech

Use this list during recurring SEO runs.

1. Review core pages:
   - home
   - services
   - about
   - blog index
   - province pages
2. Check for:
   - duplicate or vague titles/descriptions
   - weak H1/H2 alignment
   - missing internal links to service pages
   - outdated copy or old positioning
   - schema opportunities
3. Review content backlog:
   - one high-intent service-support topic
   - one authority-building informational topic
   - one local/province reinforcement idea
4. Prefer one to three safe improvements per run.
5. Validate before considering work complete.
