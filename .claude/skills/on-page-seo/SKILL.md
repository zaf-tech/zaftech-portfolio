# On-page SEO

Use this skill to make page-level search improvements without turning the site into spam.

## Workflow
1. Identify the page's main intent and adjacent intents.
2. Review its title, description, H1/H2 structure, hero copy, CTA language, and anchor text.
3. Compare against nearby pages to avoid cannibalization.
4. Draft concise edits that improve clarity, relevance, and CTR.
5. Record recommendations in `_workspace/02_on-page-edit-plan.md` before applying risky copy changes.

## Good outcomes
- each core page owns a distinct intent
- titles are specific and commercially useful
- descriptions read naturally and support clicks
- headings reinforce topic coverage
- internal links use meaningful anchor text

## Guardrails
- No keyword stuffing.
- No fake urgency or false guarantees.
- Keep brand voice: enterprise, credible, compliance-aware, practical.
